# 🌤️ HavaPusula - Modern Hava Durumu Platformu

HavaPusula, Türkiye genelindeki tüm il ve ilçeler için en güncel, detaylı ve kullanıcı dostu hava durumu tahminlerini sunan modern bir web platformudur.

🔗 **Ana Sayfa:** [havapusula.com.tr](https://havapusula.com.tr)

## 📍 Hızlı Erişim - Büyük Şehirler

Sık aranan bölgelerin güncel hava durumu ve 15 günlük tahmin raporlarına aşağıdaki linklerden ulaşabilirsiniz:

- 🌆 **[İstanbul Hava Durumu](https://havapusula.com.tr/hava/istanbul)** - Saatlik ve 15 Günlük Detaylı Tahmin
- 🏛️ **[Ankara Hava Durumu](https://havapusula.com.tr/hava/ankara)** - Güncel Meteorolojik Veriler
- 🌊 **[İzmir Hava Durumu](https://havapusula.com.tr/hava/izmir)** - Ege Bölgesi Hava Tahmini
- 🏖️ **[Antalya Hava Durumu](https://havapusula.com.tr/hava/antalya)** - Turizm ve Deniz Suyu Sıcaklıkları
- 🚜 **[Bursa Hava Durumu](https://havapusula.com.tr/hava/bursa)** - Güney Marmara Hava Durumu Raporu

## 🚀 Öne Çıkan Özellikler

- **🎯 Hassas Konum Tahmini:** Türkiye'nin her noktası için koordinat bazlı veri işleme.
- **📊 Görsel Grafikler:** Sıcaklık ve yağış ihtimallerini saniyeler içinde analiz edin.
- **📅 Uzun Vadeli Tablolar:** 7 ve 15 günlük planlarınız için güvenilir meteorolojik veriler.
- **⚡ Işık Hızında Deneyim:** Speculation Rules API desteği ile anlık sayfa geçişleri.
- **📰 Güncel Blog:** Hava olayları ve meteoroloji dünyasından en yeni haberler. [Blogumuzu okuyun](https://havapusula.com.tr/blog).

## 🛠️ Teknoloji Yığını

Bu proje modern web teknolojileri ve en iyi SEO uygulamaları kullanılarak geliştirilmiştir:

- **Framework:** Next.js (App Router)
- **Veri Kaynağı:** Open-Meteo API
- **Performans:** Cloudflare Workers Proxy, bfcache, Speculation Rules API
